# Simplex-method

This project investigates the performance of different pivot-selection rules used in the Simplex method for linear programming.

## Project Overview

I implemented and compared several Simplex pivot-selection strategies, including:

- Bland's Rule
- Largest Subscript Rule
- Largest Change Rule

The aim was to compare how the different rules affected algorithm performance and execution time across a range of linear programming problems.

## What I Did

- Implemented the Simplex method in Python
- Added multiple pivot-selection strategies
- Generated and tested optimisation problems
- Recorded execution times for each method
- Compared empirical performance across different problem sizes
- Analysed the results in a technical report
